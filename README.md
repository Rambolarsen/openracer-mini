# OpenRacer Mini

An open-development project for compact FPV racing frames, prioritizing performance, repairability and low mass.

| Variant | Mini 3 | Mini 3.5 |
|---|---|---|
| Propellers | 3 inch | 3.5 inch |
| Battery | 3S | 4S |
| Electronics | HDZero AIO15 + Lux | HDZero Gamma 45A + Race V3 + Nano 90 |
| Wheelbase target | 116 mm | 136 mm |
| Frame mass target | 15–20 g | 25–30 g |
| Flying mass target | 100–120 g | 150–180 g |

All numerical targets are provisional. No flight-ready design exists yet.

## Roadmap
Prototype Mini 3 first, validate retention and electronics fit, manufacture carbon, flight test, then develop Mini 3.5 using proven concepts.
